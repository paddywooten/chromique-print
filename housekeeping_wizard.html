Sign In (manager)

1 Delete Test Orders

The rules verification may have left a harmless test order named RULES-TEST in your order list. Scan and remove it.

2 Remove Old Passcode Documents

From the shared-passcode days: settings/admin_passcode and settings/staff_passcode. Firebase Auth replaced them — they're dead weight now.

3 Clean Up Legacy Staff Profiles

Staff added before the upgrade have a profile but no login account — they can't sign in. Delete them here, then re-create anyone who still works for you in the dashboard (Manage Team Accounts) so they get a real login.

4 Retire the Wizard Pages

setup_wizard.html and housekeeping_wizard.html (this page) have done their job. They are not part of your deployed website (the docs/ folder), so nothing leaks — but for tidiness, delete both files from the project folder once you're finished here. If you ever need them again, they're in your git history.

5 Push Everything to GitHub

All code changes are committed locally. From the project folder on your computer, run:

git push origin main

If GitHub Pages serves your site from the docs/ folder, the live site updates automatically a minute or two after the push.
